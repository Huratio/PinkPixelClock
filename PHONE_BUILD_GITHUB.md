# Build this APK from your phone

1. Open https://github.com in Chrome and sign in.
2. Create a new repository, e.g. `PinkPixelClock`.
3. Upload the contents of this project folder, including `.github/workflows/build.yml`.
4. Open the repository's **Actions** tab.
5. Choose **Build Pink Pixel Clock APK** and tap **Run workflow**.
6. Wait for the workflow to finish successfully.
7. Open the completed run and find **Artifacts**.
8. Download `PinkPixelClock-debug-apk`.
9. Extract the downloaded ZIP and install `app-debug.apk`.
10. Add **Pink Pixel Clock** from your home-screen Widgets list.

No PC or AndroidIDE is required.
